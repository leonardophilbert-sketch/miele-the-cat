# 🐱 Miele The Cat: Pixel Adventure

A retro pixel art Flappy Bird-style game built in a single, self-contained HTML file.

## 🎮 Features
- **1:1 Pixel Art Cat Sprite**: Recreated with custom animations (gliding, leaping, diving, meowing :3).
- **Fish Collectibles**: Catch Orange Goldfish, Swift Blue Guppies, Golden Starfish, and Rainbow Prismatic Fishes between pipes!
- **Cat Wardrobe & Shop**: Unlock hats (Chef, Crown, Party Cone, Sunglasses, Pirate, Angel Halo) and cosmetic trails (Nyan Rainbow, Star Dust, Bubbles, Fish Bones, Hearts, Fire).
- **8-Bit Web Audio Synthesizer**: Flap chirps, kitten meows, fish pickup arpeggios, and looping chiptune BGM directly synthesized in the browser.
- **iPhone / Mobile PWA Ready**: Optimized for touch, safe area notches, and fullscreen Home Screen web app mode.

## 🕹️ Controls
- **Fly / Flap**: Spacebar, W, Up Arrow, or Touch / Left Click
- **Meow**: M key or [MEOW] button
- **Pause**: P key
- **Shop**: [SHOP] button
- **Mute**: [SOUND] button

## 📱 How to Play on iPhone
1. Open the GitHub Pages link in Safari on your iPhone.
2. Tap the **Share** button (box with arrow up) at the bottom.
3. Tap **Add to Home Screen**.
4. Launch from your home screen for full-screen arcade gameplay!
